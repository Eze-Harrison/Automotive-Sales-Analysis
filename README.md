# Automotive-Sales-Analysis
# Project Overview
In this project, I analyzed automotive sales performance using Excel. The dashboard provides insights into revenue generation, customer performance, product line contribution, and regional sales trends.The goal of the project is to transform raw sales data into meaningful business insights through data cleaning, analysis, and visualization.

# Key Metrics

Total Units Sold: 99,067

Total Revenue: $10,032,681

Average Revenue: $101.27

# Key Insights

Classic Cars generated the highest revenue contribution at 39.07%.

Euro Shopping Channel was the highest-performing customer.

EMEA territory generated the highest revenue overall.

Revenue trends peaked strongly in November.

Madrid recorded the highest sales among all cities analyzed.

# Features of the Dashboard

Interactive slicers for Country, City, and Status

Revenue analysis by territory

Top customer analysis

Product line revenue comparison

Monthly revenue trend analysis

Top-performing cities visualization

# Recommendations

Increase focus on high-performing product lines such as Classic Cars by advertising.

Strengthen customer retention strategies for top customers by offering discounts from time to time.

Expand sales efforts in high-performing territories like EMEA.

Investigate reasons behind low-performing regions to improve revenue.
